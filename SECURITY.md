# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in UNPD, please report it responsibly:

1. **Do not** open a public GitHub issue.
2. Email the vulnerability report to `lakeg4merx@gmail.com` with the subject line `[SECURITY] UNPD Vulnerability Report`.
3. Provide detailed steps to reproduce, including environment details (Windows build, host/VM hypervisor, target kernel architecture).
4. Allow up to 48 hours for an initial response before coordinating public disclosure.
